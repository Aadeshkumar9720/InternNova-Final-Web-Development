# InternNova Official Homepage Redesign

**Project type:** Mandatory real-world redesign task  
**Student:** Aadesh Kumar  
**Stack:** HTML5, CSS3, Vanilla JavaScript  
**Reference:** https://internnova.co.in

## Project Overview

This project is an original homepage redesign concept for InternNova. The existing site was reviewed for its internship-focused content and current program positioning, then reorganized into a modern, responsive homepage with stronger visual hierarchy and clearer conversion paths.

The redesign is intentionally **not a copy of the existing website**. It uses an original layout, typography system, component style, dashboard illustration, cards, spacing, interactions and responsive behavior.

## Design Decisions

- Clearer hero message and primary call-to-action.
- Stronger information hierarchy from awareness → programs → learning model → proof → FAQ → application.
- Internship programs are presented as scannable cards.
- Domains are separated into a dedicated visual section.
- A learning roadmap communicates how the experience works.
- Workshop and mentorship content gets its own visual treatment.
- Testimonials are interactive rather than static.
- FAQ uses an accordion interaction to reduce page clutter.
- Mobile navigation collapses into a menu.
- Scroll reveal, counters, program switching, testimonial controls and back-to-top behavior add interaction without external frameworks.

## Current-Site Analysis Used for the Redesign

The reference site positions InternNova around virtual internships and learning tracks. Its current premium track content includes Python, Java, Cybersecurity, AI/ML, Full Stack Web Development, Data Analytics/BI and HR. Current public-facing social content also highlights Web Development, Data Analytics, Cyber Security, Artificial Intelligence, Python and Java as career-focused domains.

The redesign therefore keeps the recognizable internship/learning positioning while simplifying the homepage into a more editorial, portfolio-quality experience.

## Run Locally

No build tool is required.

1. Download or clone the repository.
2. Open `index.html` in a modern browser.
3. Scroll through the complete homepage and test all interactive controls.

For the best development workflow, use VS Code with Live Server.

## Deployment

This project can be deployed directly using GitHub Pages, Netlify or Vercel because it is a static HTML/CSS/JavaScript project.

### GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and `README.md`.
3. Open **Settings → Pages**.
4. Select the main branch and root folder.
5. Save and use the generated live URL for submission.
